# RQ3: Mismatch Analysis

This question emerged from an intuitive but difficult concern: places with substantial night-time movement might not be the same places where observed public-transport use is strongest. Exploring that possible divergence helped clarify what the available OD and transport datasets could—and could not—support. The work was ultimately removed as a formal research question, but it remains an important record of how the dissertation's evidential boundary was established.
