# Historical standalone LNWC spatial map

This compact record preserves an earlier standalone choropleth of the seven-part
London Night Workers Classification at LSOA level. It was generated on 19 August
2026 while the repository's paper-facing figure layer was being consolidated.

The image is not byte-identical to the LNWC figure embedded in the submitted
dissertation. It uses an earlier title, legend and map presentation, but the same
underlying classification concept. It is therefore retained as a superseded
visual result rather than placed among the final paper-matched figures.

- [`outputs/figures/lnwc_lsoa_spatial_distribution_map.png`](outputs/figures/lnwc_lsoa_spatial_distribution_map.png) is the original historical output.
- [`src/make_lnwc_map.py`](src/make_lnwc_map.py) is the original generating script.
- The final submitted presentation remains [`results/figures/lnwc_spatial_distribution.png`](../../../results/figures/lnwc_spatial_distribution.png).

The original script retains its historical workspace-relative paths. Before any
reuse, route its inputs through the current `authorised_data` interface. This map
is descriptive and adds no separate statistical finding.
