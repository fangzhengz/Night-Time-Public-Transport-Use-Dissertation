# LOAC as an alternative contextual lens

Before the final contextual narrative settled on LNWC and the twenty continuous indicators, the London Output Area Classification was tested as a categorical description of the areas surrounding the transport-use clusters. This branch asks whether externally defined neighbourhood types align with the fixed Rail and Bus typologies.

The analysis retains its lookup preparation, mode-specific association code, audit tables, figures and reports. It was not adopted in the dissertation's final Results structure because it overlaps with, but does not replace, the more interpretable LNWC and continuous-variable layers.

LOAC remains an area-level classification. Its associations must not be read as passenger characteristics or causal explanations, and historical coverage/sample definitions in this folder should not be combined with the final 800m context results without a fresh rerun.
