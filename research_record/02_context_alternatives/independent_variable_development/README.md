# Developing the twenty-variable urban context layer

The final contextual analysis did not begin as a fixed list of twenty indicators. Variables were assembled from several Census, deprivation and employment sources, checked for coverage and collinearity, and then interpreted as an external portrait of already-fixed Rail and Bus clusters. This folder preserves that development work behind the compact final tables.

It includes source definitions, correlation diagnostics, omnibus and cluster-versus-rest tests, fuller profile matrices and draft reporting material. Some code was promoted into `analysis/04_urban_context/`, while the adopted compact evidence is published under `results/tables/`.

The historical outputs should be read as the ancestry of the final context layer, not as an additional model. They describe area-level association after clustering and do not identify passengers, establish causal influence or measure a variable's contribution to forming the clusters.
