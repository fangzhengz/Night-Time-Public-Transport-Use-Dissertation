## Notes

- **Figure number finalised 2026-08-16: Figure 3.3.4.1**, matching the
  Methodology's `3.3.4` catchment-linkage subsection. File is
  `final_figures/Figure_3_3_4_1_rail_catchment_map.png`.
- **Style finalised 2026-08-16.** Slate blue-grey catchments on a
  CartoDB PositronNoLabels basemap (no place-name text competing with the
  dense central catchments), chosen over an amber/Voyager and a
  mauve/Positron-with-labels alternative. Deliberately does not reuse any
  colour from the Chapter 4 cluster palette in `COLOUR_AND_LABEL_REGISTER.md`.
  The script now only produces this one version.
- **Basemap dependency.** The generator script uses `contextily` to fetch
  CartoDB Positron tiles at render time, which requires internet access and
  the `contextily` / `matplotlib-scalebar` packages. If PROJ/GDAL environment
  variables are polluted by another local install (e.g. a PostgreSQL/PostGIS
  installation setting `PROJ_LIB`/`GDAL_DATA` globally), unset those variables
  before running the script, or basemap tile fetching will fail with a PROJ
  "DATABASE.LAYOUT.VERSION" error.
- Station points are plotted from the same GeoJSON's `lon`/`lat` columns
  (the station's own coordinate), not the catchment polygon's centroid.
