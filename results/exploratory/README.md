# Exploratory and unadopted results

This page is the shortest route into completed side analyses and questions that
were explored but not used as evidence in the submitted dissertation. The main
results remain in the parent `results/` directory. Nothing linked below changes
the adopted Rail K=5, Bus K=4, 800 m Rail-context or 20-variable specifications.

The files are not duplicated here. Each link opens the authoritative historical
copy under `research_record/`, together with its code, tables, figures and status
notes. This avoids two copies of an old result silently diverging.
